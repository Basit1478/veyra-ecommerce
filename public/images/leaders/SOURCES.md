# Archival portrait sources

These portraits are used in the Azadi gateway and were downloaded from Wikimedia Commons.

The website displays AI-assisted charcoal-and-graphite sketch derivatives created from these public-domain/CC0 identity references. The generated website assets use the `*-sketch-v2.webp` filenames; the source photographs are retained here for provenance.

- Muhammad Ali Jinnah — Public domain (Pakistan): https://commons.wikimedia.org/wiki/File:Jinnah_portrait.jpg
- Fatima Jinnah — CC0: https://commons.wikimedia.org/wiki/File:Fatima-Jinnah-address-for-Sultan-Artist.jpg
- Allama Muhammad Iqbal — Public domain (Pakistan): https://commons.wikimedia.org/wiki/File:Muhammad_Iqbal.jpg
- Liaquat Ali Khan — Public domain (Pakistan): https://commons.wikimedia.org/wiki/File:Liaquat_Ali_Khan,_Prime_minister_portrait.jpg
